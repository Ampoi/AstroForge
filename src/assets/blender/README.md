# Generated Blender visuals

Generated by `scripts/build-blender-parts.py` from AstroForge's original
mechanical models. Do not hand-edit the base64 arrays. Editable source,
regeneration and export instructions, and visual review are in
[`assets/blender/README.md`](../../../assets/blender/README.md).

`src/blender-models.ts` reconstructs indexed geometry and the named animation
hierarchy synchronously for the workshop, thumbnails, flight and debris.
`manifest.json` records source/export hashes and geometry budgets.
