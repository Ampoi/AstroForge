# Launch Complex 01

画像生成で検討した大規模発射施設を、Blender 5.2.2 LTSでモデリングした景観アセットです。少し近未来の白い外装・グラファイト色のトラス・控えめな青緑の誘導灯を使い、VABの開口から発射台まで幅28 mの搬送路を連続させています。

## 構成

72 mの整備塔（クレーン頂部84 m）、外階段、作業デッキ、格納位置のサービスアーム、94 mの避雷設備、垂直タンク4基、球形タンク3基、配管ラック、給水塔、電力設備、運用棟、搬送車、道路、外周設備を配置しています。VABは76 × 90 × 57 mで、扉の奥にも床・作業デッキ・屋根トラスがあります。

Blenderでは施設ごとのコレクションと材質ごとのメッシュに分かれています。75メッシュ・約12.7万三角形で、GLBは約5 MBです。Blenderのカメラ・照明・確認用地面はGLBに含みません。PBR材質のみなので、外部テクスチャや追加デコーダーのダウンロードは不要です。

## 再生成

リポジトリルートで実行します。通常のアプリ起動・ビルドにBlenderは不要です。

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup \
  --python scripts/build-launch-complex.py -- --render
```

`--render`を省略すると.blend・GLB・統計だけを生成します。スクリプトの寸法はThree.jsと同じX/Y/Z（Y上向き）で、BlenderへZ上向きに変換してからglTFのY上向きへ書き出します。

Blenderで直接編集した内容をアプリに反映する場合は、施設コレクションのメッシュのみを選択して、glTF Binary、Selected Objects、+Y UpでGLBを書き出します。再生成スクリプトを実行すると直接編集は置き換わるため、手動編集版は別名で保存してください。

## 接地面と重なり

ロケットの接地基準Y=0と既存の92 m四方のエプロン（Y=-0.845）を維持しています。中央の上昇軸にクレーンやサービスアームを置いていません。深い掘削トレンチは既存の地形と干渉するため、写真案の形状を浅い火炎排出路と側壁に置き換えています。

発射台エプロンとVAB床は搬送路部分を切り欠き、道路は矩形の和集合から面を生成します。同じ場所に床の上面を積み重ねません。全景表示時のカメラ近クリップ面も距離に応じて調整し、細い表面ディテールの深度精度を確保しています。

これは描画用の環境モデルです。既存の発射台・地形以外の建物、搬送路の短い取付スロープ、階段、配管などに新しい物理コライダーや搬送機能は追加していません。

## 確認

```sh
node --import tsx --test tests/launch-complex.test.js
npm test
```

専用テストはGLBを実際に読み、寸法・有限座標・描画規模、接地面、上昇軸、VABへの連続した搬送路、搬送用開口、床・交差点の重複面を確認します。

開発サーバーの `/tests/launch-complex.html` では本番のRocketScene・地形・照明・ロケットを使って、全景、発射台、搬送路、通常の飛行画面を切り替えられます。GLB読み込み失敗時は既存寸法の簡易エプロンを残し、エラーを記録します。
