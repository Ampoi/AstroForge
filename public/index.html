QUICK START

組み立てて、コードで飛ばす。

01

ロケットを組み立てる最初の胴体パーツを作業場に配置してルートを作ります。パーツを選んで接続点へ近づけるとスナップ。ドラッグでは子パーツも一緒に移動し、ルートから外れたパーツ群は半透明になります。半透明のパーツは機体の集計・保存・発射に含まれません。再接続で復帰し、Escで取消、⌘Zで元に戻せます。

02

発射台に配置する「発射台へ」を押してフライト画面に移動し、機体一覧でUDPをONにします。発射台と周辺施設は⌂ボタンで見渡せます。

03

UDPでフライトを制御する追尾中の機体の接続コマンドを別のターミナルで実行すると、UDPで点火・姿勢制御を行います。2段機体では燃料切れを検出し、下段を切り離してから上段を点火します。複数機体は一覧の「接続コマンド」からそれぞれ起動できます。「地球全景」では飛行履歴と予測軌道を確認できます。

npm run demo
