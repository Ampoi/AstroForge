# 雲・大気の描画負荷

雲は軽量な描画近似です。気象計算とは独立しており、低層の厚み、中層の小さな塊、高層の薄い筋を描き分けます。

| 層 | 設定した高度 | 描画する特徴 |
| --- | --- | --- |
| 低層 | 0.9〜3.0 km | 積雲・層積雲に似た塊、平らな雲底、丸い上面 |
| 中層 | 5.0〜5.7 km | 高積雲に似た小さな塊が広がる薄い層 |
| 高層 | 9.5〜10.5 km | 巻雲に似た透ける細い筋 |

雲の分類と形状は [NWS Cloud Classification](https://www.weather.gov/lmk/cloud_classification) を参考にしています。高度は代表的な描画設定で、実際の雲底高度は緯度や気象条件によって変わります。低層は体積をサンプリングし、中層・高層は各高度帯の中央に置いた薄い球殻で近似します。凝結・降水・対流・雲の生成消滅は計算しません。

## 負荷を抑える仕組み

- 雲の形状ノイズと陰影用の法線を起動時に一度生成します。元データは64³ RGBA、1 MiBです。
- 各視線サンプルから再び太陽方向へ探索する処理を廃止し、事前生成した情報で陰影を近似します。
- 低層は球殻の各区間を4点で調べ、中層・高層は球殻との交点だけで評価します。
- 飛行・地球全景の両方で、雲を含む背景の描画先を各辺35%、最大16万画素に制限します。高DPIでも雲の計算量が増え続けません。
- 合成時に地球の深度を画面解像度で復元し、軌道線の遮蔽を保ちます。機体・発射場は画面解像度で描画します。

この予算では遠景の色や雲の細部が柔らかくなります。雲の自己遮蔽と地表への雲影は近似です。

## 変更前後の計測

2026-09-25、同一ブラウザー・同一GPUで計測。変更前は `a148bfe`。1280×720、DPR 1、視点ごとにウォームアップ3フレーム、測定12フレーム。WebGLの `EXT_disjoint_timer_query_webgl2` によるGPU時間の中央値です。

| 視点 | 変更前 | 軽量化後 | 削減率 |
| --- | ---: | ---: | ---: |
| 地上 | 13.88 ms | 1.39 ms | 90.0% |
| 低層雲内 | 13.42 ms | 1.42 ms | 89.4% |
| 雲上 | 13.14 ms | 1.41 ms | 89.3% |
| 地球全景 | 10.11 ms | 1.43 ms | 85.9% |

空・雲・地球の背景パスと合成の値で、機体・発射場・UI・物理計算は含みません。アプリ全体のFPSや、別GPUでの性能を示す数値ではありません。

## 再計測と目視確認

```sh
npx vite --host 127.0.0.1 --port 5197
```

`http://127.0.0.1:5197/tests/environment-benchmark.html` を開き、**Run benchmark** で再計測できます。GPUタイマーが利用できない場合はピクセル読み戻しを使い、結果に計測方法を表示します。異なる方法の数値を直接比較しないでください。比較時は他のアニメーション画面を閉じます。

`http://127.0.0.1:5197/tests/environment.html` では地上・低層雲内・中層・高層・雲上・地球全景・夜・編集画面を確認できます。地球全景の横断線は、惑星の内部に重なる部分が隠れることを確認するためのものです。
