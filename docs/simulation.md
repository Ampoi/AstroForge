# 複数機体・衝突・時間倍率

## 同じ世界で飛ばす

全主機体と分離物は同じ物理時刻で更新されます。新しい機体はその時刻の地球自転に合わせて発射台に配置します。VABを開いても、ブラウザを閉じても、サーバーが動く間は飛行が続きます。

カメラの追尾対象はブラウザ単位、UDPのON/OFFは機体ごとにサーバーで共有します。専用ポートで複数機体を同時制御できます。主機体は12機まで保持します。分離物は追尾できますが、UDP制御はできません。

## 衝突と破損

地面との接触は機体の向きと胴体の接地範囲から判定します。機体同士はパーツに沿って配置した近似球の相対移動を検査し、高速ですれ違った際のステップ間の通り抜けも検出します。

| 衝撃速度 | 地面 | 機体同士 |
| --- | --- | --- |
| 4 m/s未満 | 直立に近ければ着地、傾いていれば停止 | 反発インパルスで速度を変更 |
| 4〜8 m/s未満 | crashedとして停止 | 反発インパルスで速度を変更 |
| 8〜65 m/s未満 | 接続部で破損・分解 | 両機体を接続部で分解 |
| 65 m/s以上 | 元の機体が消失 | 両機体が消失 |

地面への衝撃は自転地表に対する速度、機体同士は接触方向の相対接近速度を用います。これらは演出と操作性のための閾値であり、実材質の強度試験を再現するものではありません。

破片は胴体パーツとそれに付いた側面パーツをひとまとまりにし、位置・資源・質量を引き継ぎます。破片にも重力と空力を計算します。破片が強く再衝突した場合は消失し、再分裂はしません。生成から20シミュレーション秒で除去します。分離直後の0.5シミュレーション秒は機体間の衝突を抑制します。

近似形状のため、細い側面パーツの先端や複雑な姿勢での接触は見た目と完全には一致しません。塑性変形、熱による破壊、燃料爆発は未実装です。

## 固定シードの地形

`shared/terrain.ts` の固定シード `73129` で架空の大陸と標高を生成します。物理と近景描画は赤道で約153 m間隔の同じ三角形格子を参照し、遠景は間引いて描画します。発射場の地面は海抜−1.12 m、デッキ上面は0 m、中央の開口部では下のエプロンに接地します。着陸後も地球と共回転し、最初の着陸フレームから地表相対速度を0にします。小さな分離物にも実際の接地範囲を使います。

海は海抜0 mの接触面です。浮力・波浪・海底は扱いません。発射施設の建物・配管などの装飾物には地形コライダーを設けていません。LiDARとカメラの地表距離は同じ高さ場への有限回数のレイマーチで近似します。マップの惑星輪郭・軌道予測は基準球面の近似を維持します。

`npm test` は発射場外、丘陵、異なる緯度経度での着陸と描画メッシュの距離、燃料消費・小型分離物、地球自転、AGLと測距の一致を確認します。`npx vite --host 127.0.0.1` で `/tests/terrain.html` を開くと、接地、起伏、大陸と極域を本体サーバーなしで確認できます。

## 倍速計算

×10は1ステップを10倍長くする設定ではありません。1/120秒の積分を、実時間1秒あたり最大1,200回行います。×200では実時間1秒あたり24,000回の固定ステップを目標とします。倍率変更で機体・時刻・軌道をリセットしません。

| 時計 | 倍率の影響 |
| --- | --- |
| 物理計算・燃料消費・破片寿命 | 倍率に従って加速 |
| GMT表示 | 実時間のUTC。加速しない |
| UDP lease / command timeout | 単調実時間。加速しない |
| UDPテレメトリ | 実時間20 Hz |
| SSE | 実時間10 Hz |

PyLoN heartbeatは`warpRate`に現在の倍率、`physicsWarp`に倍率が1より大きいかを通知します。テレメトリ間の物理時間は×10で約0.5秒なので、外部コントローラーの応答は粗くなります。×200では約10秒進みます。20倍以上は危険な高速モードで、操縦・点火・分離のタイミングが間に合わない場合があります。

1回のループは実時間250 msまで、最大300固定ステップを追いつき計算します。OSスリープなどの長い遅延は切り捨て、`connection.slowFrames`を増やします。多数の機体ではCPU負荷によって実効速度が設定値に届かない場合があります。

## 物理モデルと制約

地球半径6,371 km、中心重力 `μ = 3.986004418e14 m³/s²`、自転 `7.292115e-5 rad/s`。慣性座標で位置・速度・姿勢quaternion・角速度を積分します。大気は地球と共回転。燃料消費で質量、重心、慣性テンソルが変化し、取り付け位置から力とトルクを計算します。

大気はUS Standard Atmosphere 1976の下層の温度勾配・静水圧モデルを使用。約86 kmより上は指数近似に切り替え、150 kmで密度を0にします。抗力は `½ρv²CdA`、翼の法線力は局所流速と迎角から計算し、取り付け位置に作用させます。遷音速抗力を近似加算します。標準大気と抗力式の根拠は [US Standard Atmosphere 1976](https://ntrs.nasa.gov/citations/19770009539)、[NASA Drag Equation](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/modern-drag-equation/) です。

これは**CFDではなく、係数ベースの教育・制御実験向けモデル**です。抗力・翼係数を実機データに合わせた同定は行っていません。失速、衝撃波、干渉流、風、加熱、材質の詳細な破壊、タンクの液体運動は詳細には扱いません。質量変化時の慣性は毎ステップ更新しますが、燃料流の角運動量・スロッシングは省略します。RCSは全ノズルの推力予算を共有する理想6軸配分器です。ポッドのリアクションホイールは角運動量飽和を省略します。

軌道は位置・速度から二体問題の接触軌道を計算します。遠地点・近地点・遠地点到達時間・離心率・周期・傾斜角を算出。地球内部に入る近地点もそのまま表示するため、弾道飛行では負値になります。地面・機体同士の衝突を判定し、8 m/s以上で接続部から分解、65 m/s以上で消失します。破片は最大20シミュレーション秒で除去します。衝突形状と強度はゲーム向けの近似です。詳細は [衝突と破損](#衝突と破損) を参照してください。月・第三天体・J2・海洋の流体力学は未実装。ドッキングと簡易パーツ熱モデルは[追加システム](./systems)を参照してください。初期機体は弾道飛行用で、地球周回軌道投入用ではありません。

ステップの物理時刻とコマンド期限の実時間は分離しています。OSのスリープなどで250 ms以上遅れた場合は実時間をすべて追いかけず計算負荷を制限し、`slowFrames`を増やします。実験中はOSをスリープさせないでください。
